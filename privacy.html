Privacy Policy

Last updated: October 22, 2026

Personal Assistant ("the app") is a private, single-user tool. It is used only by its owner to manage the owner's own Google Calendar. No other users can sign in to it.

Data the app accesses

With the owner's permission, the app reads and writes events in the owner's Google Calendar (scope: https://www.googleapis.com/auth/calendar). It writes only to calendars the owner has explicitly allowed.

How the data is used

Calendar data is used only to answer the owner's requests, create or update events the owner asks for, and send the owner a daily summary and reminders through the owner's own Telegram bot. To understand requests, the text of the owner's messages and relevant event details are processed by Anthropic's Claude AI service.

Storage and sharing

The app runs on the owner's personal computer. Access tokens and settings are stored only on that computer. Calendar data is not sold, not shared with third parties other than the services listed above, and not used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
